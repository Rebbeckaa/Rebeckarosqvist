hjärta vårdcentral

A guided booking flow that helps patients book medical appointments with clarity and confidence.

Overview

Hjärta Vårdcentral is a fictive mobile application concept designed to help patients book medical appointments with clarity and confidence. As a solo project, it focused on creating a structured, step-by-step booking flow that reduces uncertainty and minimises incorrect bookings — for both patients and healthcare staff.

The problem

Patients experienced confusion when navigating the digital booking system. It was unclear which type of appointment to choose, how the booking process worked, and how to cancel or reschedule.

This led to incorrect bookings and additional administrative work for the clinic's staff.

The solution

A guided, step-by-step booking flow with a progress indicator, clear descriptions at each stage, and a summary screen before confirmation.

The design gives patients full overview and control — from selecting an appointment type to receiving a booking confirmation.

User testing

Usability testing is the next step for this project — validating the flow with real users and iterating on the booking steps. Coming soon.
